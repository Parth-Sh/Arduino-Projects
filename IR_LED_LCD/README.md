# IR_LED_LCD

## A simple Arduino project that uses an IR remote to control an LED, with feedback displayed on a 16x2 LCD.

## Features

- Toggle LED ON/OFF
- Fast Blink mode
- Slow Blink mode
- Fade in and out
-  LCD shows current mode and status
- IR codes mapped to specific remote buttons

## Components Used
      
- Arduino Uno R3 
- IR Receiver Module  
- IR Remote           
- 16x2 LCD Display(without I2C)    
- LED                 
- 10k Potentiometer   
- Jumper Wires        
- Breadboard
